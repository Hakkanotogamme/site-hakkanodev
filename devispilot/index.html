L'appli des micro-entrepreneurs français.

Besoin d'aide ?

Écrivez à contact@hakkanodev.fr. Nous répondons sous 48 heures, jours ouvrés.

Je ne reçois pas le code par e-mail

Regardez dans vos courriers indésirables, puis touchez « Renvoyer un code » dans l'appli.

J'ai oublié mon mot de passe

Sur l'écran de connexion, touchez « Mot de passe oublié ? ». Un code vous est envoyé par e-mail.

Je me suis trompé sur une facture

Un document émis ne se modifie pas : la loi l'interdit. Ouvrez la facture, touchez « Autres actions », puis « Annuler ou rembourser (avoir) », et refaites une facture si besoin.

Comment supprimer mon compte ?

Dans l'appli : Accueil, engrenage en haut de l'écran, puis « Supprimer mon compte ». L'appli vous propose d'abord d'exporter vos documents, que vous devez conserver.
